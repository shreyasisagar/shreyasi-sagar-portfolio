# Dr. Shreyasi Sagar — Portfolio Website

A responsive, static HTML/CSS/JavaScript portfolio designed for free hosting on GitHub Pages.

## Files
- `index.html` — page content
- `styles.css` — layout and styling
- `script.js` — mobile navigation and footer year

## Preview locally
Open `index.html` in a browser. Google Fonts are loaded from the web; system fallback fonts are included.

## Publish on GitHub Pages
1. Create a **public** GitHub repository, for example `shreyasi-sagar-portfolio`.
2. Upload all three files (`index.html`, `styles.css`, `script.js`) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for the Pages deployment to complete. GitHub will show the published URL in the Pages settings.

For a user-site URL like `https://USERNAME.github.io`, name the repository `USERNAME.github.io`. Otherwise, a project repository gets a URL like `https://USERNAME.github.io/REPOSITORY/`.
